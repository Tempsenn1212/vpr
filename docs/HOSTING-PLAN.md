# План автономного размещения

Ориентир пользователя: около **2 000 ₽ в год** за инфраструктуру. Приложение должно работать при выключенном домашнем компьютере.

Рассматриваемый вариант: [UltraVDS](https://ultravds.com/), промотариф **UltraLite** — 1 ядро, 512 МБ памяти, SSD 10 ГБ и IP-адрес. На момент обсуждения опубликована цена 160 ₽/месяц при годовой оплате, то есть **1 920 ₽/год**. Перед заказом необходимо проверить доступность тарифа, итоговую сумму и условия продления.

Адрес — бесплатный поддомен [DuckDNS](https://www.duckdns.org/), HTTPS — [Let's Encrypt](https://letsencrypt.org/). Интерфейс и API должны быть доступны на одном HTTPS-адресе через обратный прокси; ngrok не требуется.

Памяти мало: перед годовой оплатой необходимо проверить приложение на выбранном сервере с небольшой нагрузкой. Предполагается Linux без графического интерфейса, запуск Node.js через systemd и сборка приложения вне сервера. Нужны автозапуск, постоянная база SQLite и резервное копирование с проверкой восстановления. Отдельное платное хранилище резервных копий в указанную сумму не включено.

**Статус:** вариант сохранён для дальнейшей работы. Сервер не заказан, деньги не потрачены, приложение на этот хостинг не перенесено.
